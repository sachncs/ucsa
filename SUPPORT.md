# Support

## Questions

For usage questions and "how do I…?" discussions, please use
[GitHub Discussions](https://github.com/sachncs/sachncs.github.io/discussions)
if enabled, or open a question in the
[issue tracker](https://github.com/sachncs/sachncs.github.io/issues) with the
`question` label.

## Bug reports

Open a [bug report](https://github.com/sachncs/sachncs.github.io/issues/new?template=bug.yml).

## Security issues

See [`SECURITY.md`](./SECURITY.md).
